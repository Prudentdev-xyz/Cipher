================================================================
HOW ALL LAYERS TALK TO EACH OTHER
================================================================

  Frontend (React + wagmi)
       │
       │── wallet connect ──────────► Ritual Testnet RPC
       │── read contract state ─────► CipherMatch.sol
       │── joinMatch() ─────────────► CipherMatchFactory.sol
       │── confirmStake() ──────────► CipherMatch.sol
       │── submitGuess() ───────────► CipherMatch.sol
       │── watchMatch() ────────────► CipherSpectator.sol
       │── placePrediction() ───────► CipherSpectator.sol
       │── getPlayerRank() ─────────► CipherRanking.sol
       │
  CipherMatch.sol
       │
       │── AI precompile call ──────► Ritual Native AI
       │── store secret word ───────► Ritual TEE (encrypted)
       │── register timer ──────────► Ritual Autonomous Scheduler
       │── release winnings ────────► Winner wallet (automatic)
       │── update rankings ─────────► CipherRanking.sol
       │── notify spectators ───────► CipherSpectator.sol
       │
  Ritual Autonomous Scheduler
       │
       │── fires closeRound() ──────► CipherMatch.sol (at 30s)
       │── triggers reveal ─────────► TEE decrypts secret word
       │── evaluates guess ─────────► Score updated onchain

  │                                                  │
  └──────────────────────────────────────────────────┘

  POINTS CALCULATION
  ──────────────────────────────────────────────────────

  After every match, CipherRanking.sol calculates:

  WIN points = base 100 + opponent_rank_bonus + stake_bonus
  LOSS points = base -80 + opponent_rank_mitigation

  Examples:
  NOVICE beats NOVICE    ──► +100 points
  NOVICE beats DECODER   ──► +180 points (big upset bonus)
  DECODER beats NOVICE   ──► +50 points (smaller gain)
  CRYPTIC beats NOVICE   ──► +20 points (minimal gain)
  NOVICE loses to NOVICE ──► -80 points
  CRYPTIC loses to NOVICE ──► -150 points (big penalty)

  Token Match bonus: +20% to all point calculations
  Free Match: base calculation only

  TIER THRESHOLDS (subject to governance)
  ──────────────────────────────────────────────────────
  0      – 999   points  ──► NOVICE
  1,000  – 2,999 points  ──► SOLVER
  3,000  – 5,999 points  ──► DECODER
  6,000  – 9,999 points  ──► CRYPTIC
  10,000+        points  ──► CIPHER ELITE
